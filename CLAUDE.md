# Working rules for this repo

- Approval before any change outside `work/`: propose the exact change, wait for a yes.
- Edit and Write tools only. No Python, sed or heredoc edits, not even for analysis scripts that touch repo files.
- Small batches: one file, or a couple of closely related edits, per response. The user reviews each diff window.
- Ask before changing an existing approach, however small.
- Design decisions are proposed and approved first; see docs/coding-style.md.
